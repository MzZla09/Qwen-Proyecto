"# Test de Inteligencia Artificial

Una aplicación web moderna y minimalista para evaluar conocimientos sobre Inteligencia Artificial. El test presenta **5 preguntas aleatorias** seleccionadas de un banco total de **20 preguntas**, garantizando una experiencia única en cada intento.

## 🚀 Características

- **Selección Aleatoria**: Algoritmo Fisher-Yates para mezclar preguntas de forma justa.
- **Diseño Limpio**: Interfaz minimalista, responsive y libre de distracciones.
- **Feedback Inmediato**: Corrección visual al instante tras cada respuesta.
- **Barra de Progreso**: Indicador visual del avance en el test.
- **Rejugabilidad Infinita**: Cada reinicio genera una nueva combinación de preguntas.

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica.
- **CSS3**: Estilos modernos, Flexbox/Grid y diseño adaptable a móviles.
- **JavaScript (Vanilla)**: Lógica del test, aleatoriedad y manipulación del DOM sin dependencias externas.

## 📂 Estructura del Proyecto

```text
.
├── index.html      # Estructura principal de la página
├── style.css       # Hoja de estilos y diseño visual
├── script.js       # Lógica del test y manejo de preguntas
└── README.md       # Documentación del proyecto
```

## 💻 Cómo usarlo

1. Abre el archivo `index.html` en cualquier navegador web moderno.
2. Responde las 5 preguntas presentadas.
3. Visualiza tu puntuación final y reinicia para intentar con nuevas preguntas.

No se requiere instalación ni servidores externos; funciona directamente desde el sistema de archivos local.

## 🧠 Banco de Preguntas

El proyecto incluye un total de 20 preguntas que cubren temas como:
- Aprendizaje Automático (Machine Learning)
- Redes Neuronales y Deep Learning
- Procesamiento de Lenguaje Natural (NLP)
- Historia y Ética de la IA
- Aplicaciones prácticas y conceptos fundamentales
